# Phase 7, Plan 1: Metrics Infrastructure and Instrumentation

## Objective

Add Micrometer as an optional compile dependency, create `BoudinMetrics` as the central
metrics facade, wire it into the `Worker` builder and down through `WorkflowDispatcher` →
`WorkflowRunner` → `WorkflowThread`, and instrument both workflow and activity lifecycle events.
After this plan, all counters, timers, and gauges are recorded whenever a `MeterRegistry` is provided.

## Context

### Current construction chain
```
Worker (Builder) 
  → new WorkflowDispatcher(taskQueue, sharedLog, workflowRegistry, eventLoop, timerWheel)
  → new ActivityDispatcher(taskQueue, sharedLog, activityRegistry)

WorkflowDispatcher.handleWorkflowStarted()
  → new WorkflowRunner(workflowId, taskQueue, sharedLog, workflowRegistry,
                       history, lastSeqnum, onComplete, eventLoop, timerWheel)

WorkflowRunner.start(startedEvent)
  → new WorkflowThread(context, impl, workflowMethod, inputBytes)
```

`BoudinMetrics` needs to be threaded through all of these.

### Metrics to record

**Workflow metrics** (in `WorkflowThread.run()`):
- `boudin.workflow.started` counter, tag: `workflowType`
- `boudin.workflow.completed` counter, tag: `workflowType`
- `boudin.workflow.failed` counter, tag: `workflowType`
- `boudin.workflow.duration` timer, tag: `workflowType` (recorded on both complete and failed)

**Activity metrics** (in `ActivityDispatcher.executeActivity()`):
- `boudin.activity.started` counter, tag: `activityType`
- `boudin.activity.completed` counter, tag: `activityType`
- `boudin.activity.failed` counter, tag: `activityType`
- `boudin.activity.retries` counter, tag: `activityType` (incremented for each retry attempt, i.e. attempts 2..N)
- `boudin.activity.duration` timer, tag: `activityType` (total time from start to final completion/failure)

**Gauges** (in `WorkflowDispatcher` and `ActivityDispatcher`):
- `boudin.worker.pending_workflows` gauge, tag: `taskQueue`
- `boudin.worker.pending_activities` gauge, tag: `taskQueue`

### Micrometer timer recording pattern
```java
long startNs = System.nanoTime();
// ... work ...
long durationNs = System.nanoTime() - startNs;
registry.timer("boudin.workflow.duration", "workflowType", type)
    .record(durationNs, TimeUnit.NANOSECONDS);
```

**File 2** (new): `src/main/java/com/cajunsystems/boudin/internal/BoudinMetrics.java`

```java
package com.cajunsystems.boudin.internal;

import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.Gauge;
import io.micrometer.core.instrument.MeterRegistry;
import io.micrometer.core.instrument.Timer;

import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * Central metrics facade for Boudin. Wraps a Micrometer {@link MeterRegistry} and
 * exposes recording methods for all workflow and activity lifecycle events.
 *
 * <p>Constructed once per {@link com.cajunsystems.boudin.api.Worker} and threaded
 * down to each dispatcher and execution component.
 */
public class BoudinMetrics {

    private final MeterRegistry registry;
    private final String taskQueue;

    private final AtomicInteger pendingWorkflowCount = new AtomicInteger(0);
    private final AtomicInteger pendingActivityCount = new AtomicInteger(0);

    public BoudinMetrics(MeterRegistry registry, String taskQueue) {
        this.registry = registry;
        this.taskQueue = taskQueue;
        Gauge.builder("boudin.worker.pending_workflows", pendingWorkflowCount, AtomicInteger::get)
                .tag("taskQueue", taskQueue)
                .register(registry);
        Gauge.builder("boudin.worker.pending_activities", pendingActivityCount, AtomicInteger::get)
                .tag("taskQueue", taskQueue)
                .register(registry);
    }

    // ── Workflow ──────────────────────────────────────────────────────────────

    public void workflowStarted(String workflowType) {
        registry.counter("boudin.workflow.started", "workflowType", workflowType).increment();
    }

    public void workflowCompleted(String workflowType, long durationNs) {
        registry.counter("boudin.workflow.completed", "workflowType", workflowType).increment();
        registry.timer("boudin.workflow.duration", "workflowType", workflowType)
                .record(durationNs, TimeUnit.NANOSECONDS);
    }

    public void workflowFailed(String workflowType, long durationNs) {
        registry.counter("boudin.workflow.failed", "workflowType", workflowType).increment();
        registry.timer("boudin.workflow.duration", "workflowType", workflowType)
                .record(durationNs, TimeUnit.NANOSECONDS);
    }

    // ── Activity ──────────────────────────────────────────────────────────────

    public void activityStarted(String activityType) {
        registry.counter("boudin.activity.started", "activityType", activityType).increment();
    }

    public void activityCompleted(String activityType, long durationNs) {
        registry.counter("boudin.activity.completed", "activityType", activityType).increment();
        registry.timer("boudin.activity.duration", "activityType", activityType)
                .record(durationNs, TimeUnit.NANOSECONDS);
    }

    public void activityFailed(String activityType) {
        registry.counter("boudin.activity.failed", "activityType", activityType).increment();
    }

    public void activityRetried(String activityType) {
        registry.counter("boudin.activity.retries", "activityType", activityType).increment();
    }

    // ── Gauges ────────────────────────────────────────────────────────────────

    public AtomicInteger pendingWorkflows() { return pendingWorkflowCount; }

    public AtomicInteger pendingActivities() { return pendingActivityCount; }

    public MeterRegistry registry() { return registry; }
}
```

In `run()`, instrument:
```java
private void run() {
    CURRENT_CONTEXT.set(context);
    long startNs = System.nanoTime();
    metrics.workflowStarted(context.workflowType);
    try {
        Object[] args = KryoSerializer.fromBytes(inputBytes);
        if (args == null) args = new Object[0];

        Object result = workflowMethod.invoke(workflowImpl, args);

        byte[] resultBytes = (workflowMethod.getReturnType() == Void.TYPE)
                ? null
                : KryoSerializer.toBytes(result);

        appendCompleted(resultBytes);
        metrics.workflowCompleted(context.workflowType, System.nanoTime() - startNs);
        context.completionFuture.complete(resultBytes);

    } catch (java.lang.reflect.InvocationTargetException ite) {
        Throwable cause = ite.getCause() != null ? ite.getCause() : ite;
        appendFailed(cause);
        metrics.workflowFailed(context.workflowType, System.nanoTime() - startNs);
        context.completionFuture.completeExceptionally(cause);
    } catch (Exception e) {
        appendFailed(e);
        metrics.workflowFailed(context.workflowType, System.nanoTime() - startNs);
        context.completionFuture.completeExceptionally(e);
    } finally {
        CURRENT_CONTEXT.remove();
    }
}
```

### Task 3 — Instrument ActivityDispatcher

**File**: `src/main/java/com/cajunsystems/boudin/internal/ActivityDispatcher.java`

Add `BoudinMetrics metrics` as the 4th constructor parameter. Add field `private final BoudinMetrics metrics;`

In `executeActivity()`, instrument the retry loop:

```java
private void executeActivity(HistoryEvent.ActivityScheduled scheduled) {
    LogTag historyTag = LogTag.of("workflow-history", scheduled.workflowId());
    int maxAttempts = scheduled.maxAttempts();
    long initialIntervalMs = scheduled.initialIntervalMs();
    double backoffCoefficient = scheduled.backoffCoefficient();
    String activityType = scheduled.activityType();

    metrics.activityStarted(activityType);
    metrics.pendingActivities().incrementAndGet();
    long activityStartNs = System.nanoTime();

    Exception lastException = null;
    try {
        for (int attempt = 1; attempt <= maxAttempts; attempt++) {
            // ...existing retry loop body...
            // On retry (attempt > 1), before the sleep:
            if (attempt > 1) {
                metrics.activityRetried(activityType);
            }
        }

        // On permanent failure (after loop):
        metrics.activityFailed(activityType);
        // ... append ActivityFailed ...
    } finally {
        metrics.pendingActivities().decrementAndGet();
    }
}
```

More precisely, the instrumentation should be:
- `activityStarted` and `pendingActivities++` before the loop
- When the loop succeeds (after `sharedLog.append(completed)`): `activityCompleted(type, durationNs)` and return
- On each catch block where `attempt < maxAttempts` (before sleep): `activityRetried(type)`
- After the loop exhausts all attempts: `activityFailed(type)`
- `pendingActivities--` in a finally block wrapping the entire loop

Because the existing code uses `return` inside the loop on success, the cleanest approach is:

```java
metrics.activityStarted(activityType);
metrics.pendingActivities().incrementAndGet();
long activityStartNs = System.nanoTime();
Exception lastException = null;
try {
    for (int attempt = 1; attempt <= maxAttempts; attempt++) {
        try {
            // ... invoke (same as before) ...
            HistoryEvent.ActivityCompleted completed = ...;
            sharedLog.append(...).join();
            log.debug(...);
            metrics.activityCompleted(activityType, System.nanoTime() - activityStartNs);
            return;
        } catch (Exception e) {
            lastException = e;
            // ... log warn (same as before) ...
            if (attempt < maxAttempts) {
                metrics.activityRetried(activityType);
                // ... sleep (same as before) ...
            }
        }
    }
    // All attempts exhausted
    metrics.activityFailed(activityType);
    // ... append ActivityFailed (same as before) ...
} finally {
    metrics.pendingActivities().decrementAndGet();
}
```
